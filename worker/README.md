# Сборщик обратной связи

Инструкция по настройке и безопасности: [../README.md](../README.md).

Этот Worker публичен, но GitHub-токен хранится только в секрете `GH_TOKEN` на Cloudflare. Для GitHub Pages токен не требуется и не должен попадать в HTML/JS.

`ALLOWED_ORIGIN` ограничивает отправку из браузера, но не защищает от скриптов, подделывающих заголовок Origin. Для открытого масштабного проекта нужна дополнительная защита от спама.

Статическая страница: https://andy-pal-hub.github.io/pw-class-test/ (проверяйте после включения Pages).
