# Подключение к действующему тесту

`integration.js` загружается перед основным inline-скриптом. `render()` сначала вызывает `PW_RESULT_VISUALS.clear()`, затем после создания результата вызывает mount с уже вычисленным именем лидера и `personality().tags`. В статусы tie/conflict сцена не монтируется.

Поддержаны три класса. Глиф для остальных классов и все текстовые результаты сохраняются. Изменён только HTML блока иллюстрации. Конструктор сцены, данные и звук загружаются по первому поддержанному результату; изображения запуска загружаются только при наличии multibox. База URL вычисляется относительно integration.js, поэтому вложенный путь GitHub Pages работает без настройки домена.

Каждая новая сцена начинает с выключенным звуком. Кнопки звука, паузы, резкости и портрета не имеют data-action и не попадают в обработчик ответов/отзывов теста. При сетевой ошибке возвращается глиф. Clear перед rerender и pagehide отменяет RAF, наблюдатели и звук, а generation token не даёт запоздавшей загрузке смонтироваться на следующем вопросе.

Файлы config.js, telemetry-client.js, worker/* и накопленные data/*.json не изменены.
