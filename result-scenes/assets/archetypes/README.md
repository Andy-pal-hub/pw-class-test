# Процедурные эффекты v3

Графические генераторы находятся в scene-engine.js, повторяющийся звук — в soundscape.js, метаданные и сопоставление тегов — в data/scenes.json.

В multibox/ находятся шесть пользовательских скринов запуска: 01…06 — хронологический порядок, исходное имя сохранено в launchSequence. Кадры содержатся в оригинальном виде и показываются целиком внутри перекрывающихся окон.

Остальные ресурсы, мешочки, сундуки, сферы, корона, звёзды, текст и шлейфы рисуются Canvas. Нет сетевых зависимостей и внешних шрифтов. Звуки и непрерывные 12-секундные петли синтезируются Web Audio; звук включается только действием пользователя.
